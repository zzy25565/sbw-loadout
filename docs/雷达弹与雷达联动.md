# 1.2.0 雷达弹与雷达联动

环境：Minecraft 1.21.1、JDK 21；默认构建 NeoForge 21.1.248，SBW 0.8.9.1，可用 `-PsbwVersion=0.8.9.2` 切换。既有模型、贴图与七件弹药数据保留。

## 安装及操作

客户端和服务端同时更新 `sbw-loadout-1.2.0.jar` 与 `sbw_radar-1.3.0.jar`，移出旧版同名模组，保留 SBW、Kotlin For Forge 等依赖。两者仍可独立安装；雷达 1.3.0 与旧挂载 1.1beta 不混用。

新弹药 ID 为 `sbw_loadout:9m336_radar`，物品 ID 为 `sbw_loadout:ammo_9m336_radar`：

```mcfunction
/give @s sbw_loadout:ammo_9m336_radar 16
```

在载具原有完整 JSON 的 `Loadout.Allowed` 数组增加 `"sbw_loadout:9m336_radar"`，保留其他载具字段。未声明 Loadout 的载具不会自动获得自定义挂载。这次没有给所有正式机型添加白名单。

1. 主手持弹药右键装填，或潜行右键进入挂载界面；坐入驾驶席。
2. 两模组同装：O 切换 SRC → TWS → TRK，J 切换目标，P 调整扫描宽度。HUD 显示 TRK 与可用制导通道后，按 SBW 原有载具开火键发射。
3. 仅装挂载模组：对准实体按 K 建立雷达弹锁定，再开火；锁定仍受服务器射程、角度和遮挡检查。
4. G 热诱弹、H 箔条：箔条可按配置概率使雷达弹脱锁，热诱弹不直接诱骗雷达弹。仍需载具具备投放条件与库存。

旧 `options.txt` 可能保留旧键位，升级后请在“控制”中将雷达模式设为 O、扫描宽度设为 P，避免与挂载的 K（TV/锁定）和 L（激光）冲突。不会改写已有玩家键位文件。

## 弹体与制导

从原雷达默认 9M336 流程移植为独立雷达弹种。外形与贴图直接复制 SBW 原始 9M336 字节，未减面或缩图；物品使用原生武器图标。推进继承 9M336 的速度更新方式，碰撞、爆炸与伤害使用 SBW 基类。原 SBW 红外 9M336 保留自身行为。

默认先爬升 12 刻、上抬 10°，中段跟随服务器 TRK；进入 96 格范围、35°视锥并有视线后转入独立末制导。切换雷达目标不会强行更改已发射导弹的目标；末段脱离发射雷达仍可继续。目标无效时沿最后位置飞行，连续失锁超过 120 刻移除；全寿命最多 1200 刻（正常 20 TPS 下 60 秒）。命中箔条后持续脱锁，不会下一刻自动重新锁回。

| 参数 | 默认值与含义 |
|---|---|
| 槽位 / 连发 | 1 / 1 |
| 发射初速 | 2 格/刻，非恒定巡航速度 |
| 冷却 | 40 刻 |
| 搜索距离 / 半角 | 512 格 / 35° |
| 转向上限 | 5°/刻 |
| 直击 / 爆炸伤害 | 260 / 90（游戏平衡值） |
| 爆炸半径 | 6 格 |
| 中段制导通道 | 最多 2，且受雷达配置上限约束 |

进入末段或被箔条诱骗会释放中段通道；满通道、未锁定、非驾驶员、同队或遮挡目标都不能通过发射校验，失败不扣弹。箔条按雷达附属配置进行范围与概率判断。独立挂载模式没有新增箔条物品。

## 对接与构建

挂载通过 `RadarLink.Provider` 接收雷达服务端有效 TRK、旧导弹已占通道与通道上限。联装后雷达不再为接管的挂载载具重复生成额外导弹，原有未接管载具仍走原雷达流程。客户端坐标不作为雷达锁定依据。

雷达弹数据在 `data/sbw_loadout/ammo/9m336_radar.json`，`Radar` 内可调整 `ClimbTicks`、`ClimbUpDeg`、`TerminalRange`、`MaxChannels`、`LostTimeout`。`/reload` 后更新；雷达弹的存档记录保留发射时配置。老弹药定义和原 API 构造方式继续可用。

源码应将 `sbw_loadout` 与 `sbw_radar` 放在同级目录，先在前者 `./gradlew clean build`，再在后者执行同样命令。运行 `-Pgametest` 或客户端 smoke 后须再 `clean build`，避免开发夹具进入发布包。`-PsporeCompat` 是本工作区的联合测试开关，需要工作区中的历史 Spore 构建产物；普通构建不依赖真菌源码。

已验证结果及截图见交付目录的验收记录。联合测试覆盖指定历史 Spore 2.2.0 源码构建，不等于验证全部真菌发行版本或完整第三方整合包。
