# 1.3.0 低空巡航弹道

完成日期：2026-10-27。Kh-59MK 与 X-555 使用独立实体 `sbw_loadout:cruise_missile`。这是 Minecraft 游戏弹道，速度单位是格/刻，没有把这些参数宣称为真实导弹的马赫数或性能复现。

## 实际行为

1. 投放后以受控速度下降到低空，保留逐刻转向限制。
2. 在飞行方向前方读取地形和水面高度，提前为山脊、树冠、建筑和狭窄障碍抬高航迹。采样也考虑正在转弯的实际航向。
3. 平稳段维持地形上方约 8 格的巡航高度；遇到障碍会暂时升高。
4. 进入末段距离且视线畅通时转向目标，移动实体目标使用当前速度估算拦截点。已对准的末段不会持续减速到悬停，以免破坏拦截时序。
5. 目标被遮挡或离开导引视场时，保留同一个目标的最后可见位置，不自动换目标；重新可见时可恢复跟踪。离座、关闭吊舱或改变操作者准星不会重设已经发射的弹体。

Kh-59MK 仍需通过原来的电视/吊舱锁定流程获得有效目标。X-555 沿用原有的游戏位置/实体目标输入。没有有效目标时拒绝发射，不扣弹。

## 参数

Kh-59MK 和 X-555 的原弹药 ID、已有挂载白名单及物品保持不变。默认发射初速为 1.2 格/刻，最大巡航速度为 1.4 格/刻，转向上限为 3 度/刻，散布为 0。独立弹体不执行 AGM-65 的原生逐刻加速。

```json
"Projectile": "sbw_loadout:cruise_missile",
"Velocity": 1.2,
"Spread": 0,
"TurnRate": 3,
"RenderProjectileModel": true,
"Cruise": {
  "Type": "LOW_ALTITUDE",
  "Speed": 1.4,
  "Clearance": 8,
  "LookAhead": 96,
  "TerminalRange": 96,
  "ClimbAngle": 40,
  "DescentAngle": 35,
  "Acceleration": 0.08,
  "MaxTicks": 3600
}
```

| 字段 | 意义 |
|---|---|
| Speed | 游戏最大巡航速度，格/刻；允许 0.2–4 |
| Clearance | 巡航目标离地/水面高度，格；允许 2–64 |
| LookAhead | 前视地形距离，格；允许 16–192 |
| TerminalRange | 进入可见目标末段的水平距离，格；允许 16–512 |
| ClimbAngle / DescentAngle | 巡航阶段爬升/下降角度限制；末段仍受 TurnRate 限制 |
| Acceleration | 加速上限，格/刻²；减速可使用其三倍以适应转弯 |
| MaxTicks | 飞行/等待寿命上限；默认 3600 刻，即正常 20 TPS 下 180 秒 |

Cruise 字段缺省时不启用此弹道。当前仅接受 TV 或 INS 前缀的导引配置，并要求绑定独立巡航实体；参数越界、非有限数或实体/弹道不匹配会使资源重载失败，保留旧快照。

Java 发射器可在服务端验证目标后调用 `GuidanceApi.cruise(projectile, ammoType, launcherUuid, targetUuid, point)`。发射时保存参数、目标、维度、阶段、飞行年龄和最后已知目标点的快照，普通存档与 SBW 超视距快照都保留这些状态。旧版 AmmoType 构造接口继续可用。

## 碰撞、拦截和区块

独立实体继续经过 SBW 的扫掠碰撞、伤害、爆炸及近防炮拦截接口。普通实体使用当前身体判定框，避免通用高速弹检测中的五刻后移造成慢弹穿过移动身体；载具仍使用 SBW 原有旋转 OBB 与装甲部件判定。不会扩大目标判定框、瞬移命中或添加无接触近炸来凑命中率。

地形只通过已加载的 `getChunkNow` 读取，巡航实体不申请强制加载。前视地形或下一步路径未加载时暂停推进；地形恢复后继续，等待也计入寿命。由此不会为了远距离飞行不断生成新地图。

## 已知边界

8 格是控制目标，并非每一刻的硬性离地保证。极近的高墙、投放点已经在地形内部、突然在弹体前放置方块、封闭山体或不可达的洞内目标都不保证可绕过。本版做前视高度规划，不做横向迷宫寻路；不提供水下巡航。地形高度图包含树冠/屋顶，可能选择从其上方通过。

目标失去视线时不会透过山体持续读取其移动；只能前往最后可见位置。移动目标的加速、急转或超过导弹可拦截速度仍可能导致脱靶。测试结果仅对记录的游戏环境与场景有效，不能解释为所有地图下的 100% 命中承诺。

## 验证与安装

自动测试使用实际弹体 tick 与真实碰撞事件计分，区分目标实体命中与撞地；验证高空/低空、偏置/近目标、山脊、单格障碍、水面、双向移动目标、原生载具 OBB 和中途读档，并检查速度、转向、离地间距、状态存档、无区块生成及近防炮击毁。最终统计、曲线和日志见 `validation/low_altitude_1.3.0`。

另有实际客户端隔离世界：通过原挂载发射入口完成 Kh-59MK 电视锁定和投放，驾驶员离座后，观察完整模型下降、巡航、越障、末段及真实目标碰撞。截图不使用冻结弹体或修改生产弹道。

客户端和服务端同时替换为 `sbw-loadout-1.3.0.jar`。通信协议已从 4 升至 5，防止旧客户端忽略新实体和参数；SBW、NeoForge、Kotlin For Forge 仍需按原要求安装。其他弹药维持既有轨迹。

参考：[NeoForge 实体数据与同步](https://docs.neoforged.net/docs/entities/data/)。具体兼容性以项目绑定的 1.21.1 / SBW 0.8.9.1、0.8.9.2 编译及运行结果为准。
