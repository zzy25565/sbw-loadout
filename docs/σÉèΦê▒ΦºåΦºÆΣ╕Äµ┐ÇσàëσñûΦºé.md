# v1.1beta：吊舱视角与激光外观更新

日期：2026-10-22。Minecraft 1.21.1 / NeoForge 21.1.240+ / SBW 0.8.9.1、0.8.9.2。客户端和服务器须同时更新；通信协议升级为 4。

## 电视制导的新操作

进入已接入 `Loadout` 的飞机或直升机驾驶席，按 **F6** 打开独立光电吊舱。此视角来自机腹传感器，独立于玩家和机头朝向，画面保持水平；不需要为单独机型新增 Java 适配或吊舱模型。

| 操作 | 默认按键 |
|---|---|
| 吊舱视角 / 返回驾驶视角 | F6；Esc 也可返回 |
| 转动吊舱镜头 | 按住鼠标中键拖动，或方向键 |
| 独立变倍 | 滚轮或 +/-：50°、25°、12°、6° FOV |
| 锁定准星处目标 / 解除 | K 或左键 |
| 稳定当前地面点 / 解除 | G 或右键 |
| 机载激光开关 | L |
| 发射当前队首挂载弹药 | Enter |
| 解除稳定并回正前下方 | R |

F6 与 K 可在游戏按键设置中修改。增大倍率时转动灵敏度随之降低；中键拖动可多次释放、移回鼠标继续转动，镜头不会受窗口边缘的累计移动量限制。

吊舱界面包括中心准星、锁定框、FREE/AREA/TRACK 状态对应的中文提示、镜头方位与仰角、测距、目标世界坐标，以及 TV 弹的 READY / HOLD 提示。**吊舱看见目标不代表弹药已经具备投放条件。** 武器仍检查自己的射程、机体前向发射射界与视线，避免让前向发射的导弹为了攻击侧后方目标突然掉头。

服务器依据吊舱的实际位置和镜头角度发出射线，优先确认可见实体；没有实体时可锁真实地面/方块表面。客户端不能直接提交任意目标坐标作为吊舱锁定结果。稳定后，飞机平移时镜头会继续指向同一地面坐标，实体跟踪则继续观察原实体。

被地形遮挡、目标消失、超出观测距离或云台限位时，界面显示丢失/限位；不会自动换锁其他实体。云台水平相对机头 ±150°，俯仰 -25° 至 +89°（正值为向下）。服务器 `podRange` 默认 2048 格，实际只使用已加载区块；游戏画面仍受客户端视距、实体追踪距离影响。`podEnabled=false` 可以禁用通用吊舱。

锁定 TV 目标后可以在吊舱内按 Enter 投放，也可以先退出视角再用原生载具开火键。已确认的 TV 目标不会被原生雷达留下的其他目标覆盖。TV 弹发射后自主跟踪，退出吊舱、离开载具或射手死亡不改变已发射弹体的导引逻辑；断照惯性与近防炮拦截规则继续保留。

吊舱观测时世界与飞机继续运行，界面接管观测输入；这是观察/投放视角，不会自动驾驶或替玩家保持高度。返回后恢复进入前的第一/第三人称视角和正常驾驶操作。离席、死亡、换维度、禁用吊舱会关闭相应会话。观测界面心跳超时也会关闭；正常返回驾驶视角后，已稳定且开启的机载激光不要求界面心跳。

## 机载激光

吊舱内按 L 开启/停止，默认编码 1688，可在服务器 `aircraftLaserCode` 设置。K 锁定实体或 G 稳定地面后照射；未锁时 L 会自动稳定当前可见落点。HUD 显示 LASER ON / MASKED / OFF 和编码。退出吊舱后已稳定的照射继续，重开后 L 关闭；解锁或回正会关激光。信号丢失与重获沿用惯性/限角逻辑，飞机源 UUID 与手持玩家源 UUID 分开。闭舱持续照射仅在原驾驶员仍驾驶原飞机时有效。

## 激光外观

指示器仍按住右键照射，但光束改为有窄核心和低透明度外晕的满亮度渲染，落点改为固定于真实命中位置的柔光光斑。光束接受世界深度遮挡，不穿墙显示。指示器自身开镜时只显示落点，避免近端光束在放大镜内变成遮挡画面的亮带；从侧面可看到发射位置与细光束。

客户端 `config/sbw_loadout-client.toml` 可调整：

| 配置 | 含义 | 默认 |
|---|---|---|
| `laserColor` | RGB 十进制颜色，例如红色 FF6060 | 16736352 |
| `laserWidth` | 光束核心半宽，格 | 0.004 |
| `showLaserBeam` | 是否显示整条光束；关闭仍显示落点 | true |

这些配置只改变本机显示，不改变服务器接收编码、照射距离、实际落点或制导效果。

## 参考与边界

激光外观方向参考 [TaCZ 配件激光配置](https://tacwiki.mcma.club/zh/gunpack/attachment/display.html)，包括颜色、宽度与独立落点的表达；吊舱视角方向参考 [战争雷霆的瞄准吊舱](https://wiki.warthunder.com/collections/weapon/tg_pod) 与 [官方更新中的目标跟踪说明](https://warthunder.com/en/game/changelog/current/1749)。本附属自行实现渲染、相机和操作界面，不依赖 TaCZ，也不包含这两个项目的贴图、模型或游戏界面素材。

本轮交付为通用光电视角和原有制导系统接入。尚未新增吊舱三维外形、实体外挂动画、热成像算法或具体弹药模型对应。原模型与贴图保持完整精度。
