# 吊舱热成像（1.3.1）

2026-10-27。适用 MC 1.21.1、NeoForge 21.1.240+、SBW 0.8.9.1 / 0.8.9.2；通信协议仍为 5。客户端与服务器使用本版完整 JAR。

## 操作

坐入支持自定义挂载的飞机驾驶席，按 F6 打开光电吊舱。每次进入默认使用 EO 可见光；点击左上角 **EO 可见光 / IR 热成像** 按钮切换。

也可使用卓越前线的“激活热成像”按键。原生默认键和本附属的锁定键都是 K，因此在吊舱内 **K 锁定，Shift+K 切换热成像**。如果将原生热成像键改到不与吊舱操作冲突的键，就可直接使用新键；若仍冲突则加 Shift。界面底部显示实际需要的组合键。无需增加或重复配置一套热成像按键。

切换 EO / IR 保持原目标、稳定点、镜头姿态、变倍与机载激光状态。滚轮仍在 50°、25°、12°、6° FOV 之间变倍。点击模式按钮只切换成像，不触发鼠标左键的锁定/解除操作。

Esc、F6 返回驾驶视角，恢复进入吊舱前的第一/第三人称与原生热成像开关状态。原先关闭时退出即关闭；原先由热成像座位或护目镜开启时退出恢复开启。离席、死亡或界面被替换也会释放吊舱对成像的接管；驾驶视角继续按 SBW 的装备资格判断。

## 原生实现与范围

直接调用 SBW `ClientEventHandler.turnOnThermalImaging()` / `turnOffThermalImaging()`，使用它的 `ThermalShaderHandler`、实体渲染配合与 `superbwarfare:shaders/post/night_vision.json`。本附属不复制这些资源，也不提供另一套颜色滤镜；最终视觉效果取决于安装的 SBW 版本与资源包。

只在有效吊舱界面内补充传感器资格，让没有原生热成像座位配置的挂载飞机也可使用吊舱 IR。关闭界面后，SBW 的座位/护目镜检查恢复。窗口缩放不覆盖进入时保存的状态；资源重载或原生后处理被释放后会重新应用当前模式。所有相关 Mixin 均在客户端列表中注册。

热成像改变本机观察画面；锁定仍由服务端使用原来的机腹射线、可见性、距离、云台限位与弹药发射条件判断。切换不授予穿地形锁定或新的探测距离。

## 验证

验收包含真实客户端中的 EO / IR 画面、默认键冲突与改键、无热成像座位持续成像、锁定保持、变倍、Screen 重初始化、后处理释放、实际资源重载、Esc/F6 返回、离席关闭，以及原有座位热成像的恢复。日志与截图见项目 `validation/thermal_1.3.1/`，最终通过结果见交付目录的验收说明。
