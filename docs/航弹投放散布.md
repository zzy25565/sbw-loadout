# 航弹投放散布（1.3.3）

本版覆盖现有全部 11 种航弹。未锁定的制导航弹可以按普通航弹投放；有效制导锁定后，取消释放瞬间的随机散布。导弹仍沿用原先的锁定和发射规则。

## 投放状态

| 状态 | 是否可投放 | 初始散布 | 投放后 |
|---|---|---|---|
| 普通炸弹 | 可以 | 有 | 重力下落，不附加导引 |
| TV 航弹未锁定、失锁或目标已消失 | 可以 | 有 | 普通炸弹下落 |
| TV 航弹有效锁定 | 可以 | 0 | 原有实体/固定点制导 |
| 激光航弹没有有效光斑、编码不匹配或光斑被遮挡 | 可以 | 有 | 普通炸弹下落 |
| 激光航弹有匹配编码的可见光斑 | 可以 | 0 | 原有持续激光与断照惯性制导 |
| INS/GNSS 坐标航弹尚未明确锁定 | 可以 | 有 | 普通炸弹下落，不自动把瞄准射线当成锁定 |
| INS/GNSS 坐标航弹已锁定真实可见坐标 | 可以 | 0 | 向锁定的固定世界坐标制导 |

驾驶视角按 **K** 或在 **F6 吊舱**里按 K/G 锁定、稳定目标；激光航弹通过吊舱 L 或同队指示器提供匹配编码的有效照射。坐标航弹锁定实体时保存该处的世界坐标，实体随后移动不会拖走坐标点。

HUD 显示 **BOMB / 普通投放 · 有散布** 或 **GUIDED / 无投放散布**。失锁后再次投放会回到普通投放，请以界面当时的状态为准。纯观察、未开启的激光、失效目标或未经服务端验证的坐标不会取消散布。普通炸弹也不会因为吊舱稳定目标而自动获得制导。

## 散布参数

由服务器在每枚航弹释放时独立采样初始速度方向，随后继续使用原生运动和碰撞。没有每刻追加随机偏移，也不会直接修改目标坐标。释放后继续继承飞机的线速度。

服务器世界的 `serverconfig/sbw_loadout-server.toml` 中新增：

```toml
bombReleaseSpread = 2.0
```

单位与弹药 JSON 的 `Spread`、原生 `Projectile.shoot` 参数相同，不是角度或固定米数。未锁定时取 `max(弹种 Spread, bombReleaseSpread)`；有效锁定后为 0，包括弹种原本配置的非零 Spread。可调范围为 0–30；设为 0 只关闭统一最低散布，弹种自身更大的 Spread 仍保留。实际落点偏差随高度、初速度、飞机速度和原生重力变化。

“无投放散布”只表示释放瞬间不加入随机角误差。飞机运动、云台/武器射界、地形、导引转弯能力、目标机动和激光丢失仍影响命中；不会把命中结果强行改成百分之百。

散布和导引状态在释放时确定。之后再锁定不会让已经按普通方式投下的炸弹突然获得导引；已经制导发射的弹体继续沿用现有自主 TV、固定点或激光惯性规则。

## 弹体和兼容范围

11 种航弹为 FX 1400、GBU-31、GBU-38、GBU-53/B、GBU-58、KAB-1500Kr、KAB-1500L、KAB-500Kr、KAB-500L、LS-500J、SPICE 1000。服务端按 `Category` 判断航弹，支持 `Bomb`、`GuidedBomb`、`UnguidedBomb`、`AerialBomb`（不区分大小写），第三方弹种可按同一声明接入。

原先复用导弹实体的航弹，在未锁定普通投放时改用原生 MK82 弹体下落，防止仍被导弹推进或默认位置制导接管；原本就是航弹的实体继续使用原实体。弹药自己的伤害、爆炸半径、模型身份和挂载消耗不变。锁定投放仍使用原配置弹体与服务端验证过的目标。

1.3.2 的全部弹药参数资源保持原值，热成像、雷达导弹与 Kh-59MK / X-555 低空巡航也保留。安装时客户端和服务端都替换为 1.3.3，网络协议仍为 5。

## 验证

新增测试通过真实挂载发射入口检查随机投放、32 次独立样本、飞机速度继承、16 次锁定投放零初始误差、TV 目标失效、激光编码与照射失效、坐标显式锁定、固定坐标不随实体移动、普通炸弹不获制导、全部 11 种正式弹药的普通投放和导弹锁定规则。

真实客户端验收包含吊舱状态同步、未锁定与锁定后按 Enter 投放、原模型显示、热成像下的锁定提示，以及解锁后的状态恢复。最终通过结果、截图和正式包校验见交付目录。
